## 1. Player fantasy

我不是在拆房子，而是在**解一道带风的抛物线题，把对面小队一个个从地形上抹掉**。打穿脚下的土，让他们摔进虚空；或者直接一发正中，把残血的人带走。

## 2. 核心循环

```
看风/看地形 → 按住向后拉弓（角度+力度）→ 松手发射 → 爆炸改地形 + 伤害
→ 回合末一次性结算（悬空/滑落/坠底/死亡）→ 敌方回合一发 → 循环
→ 一方全灭 → 结算金币/碎片 → 升星 / 练训练 / 解锁英雄与名额 → 更强的对手
```

- 每回合双方各行动一次（`round` 在 AI 行动结束后 +1）。
- 14 回合结束进入**猝死**：从第 15 回合起每回合全体单位掉血并逐回合加重，保证有限步终局。
- 胜负：**一方英雄全部阵亡即负**；同批阵亡判当前行动方负。

## 3. 控制模型（已实现）

- 横屏单指；**反向拉弓**：按住战场向反方向拖（左下拖 = 向右上打），拖拽距离 / 180px = 力度，松手发射。
- 手指不遮挡落点；力度环 + 含风预测弹道实时显示；短拖（<14px）取消。
- 底部英雄头像**可点击选人**（仅玩家回合、存活英雄），不点则按轮转自动换人。
- 菜单/结算弹窗打开时 gate 掉战斗输入；开战与首次触摸会请求浏览器全屏。

来源：`view/aim.ts`、`view/scenes/BattleScene.ts`、`ui/HudController.ts`。

## 4. 地图与对手

- **4 张地图**（`config/maps.ts`）：黄昏高地 / 碎骨裂谷 / 双峰隘口 / 赤岩台地，按已打场次轮换；两侧高地高度固定（468），保证站位公平。
- 对手人数跟随玩家名额：简单少 1、普通相同、困难多 1（2–4 人）。
- 对手星级与训练随 `battleIndex` 与难度提升，不额外加隐藏数值。

## 5. 英雄与武器（7 人 7 武器）

| 英雄 | 武器 | 定位 |

| 侦察 | 侦察集束 | 15 枚小弹覆盖 |

| 迫击 | 迫击重弹 | 超远高抛、爆炸半径最大 |

## 6. 养成闭环（MVP）

资源只有 `coin` / `shard` 两种：

1. **英雄升星**：1–5★，生命 ×(1+0.18(n-1))，伤害 ×(1+0.12(n-1))，花费 `round(40×1.6^(n-1))` 金币。
2. **队伍训练三条线**（1–3 级，`round(30×1.55^(n-1))` 金币）：
   - 火力：全队伤害 +6%/级
   - 护甲：全队生命 +8%/级
   - 工兵：爆炸挖地半径 +10%/级
3. **英雄解锁**：升星总数达标免费解锁（乌鸦 5★、医疗 7★、迫击 10★、工兵 14★），也可用碎片直接解锁（3/4/6/8）。
4. **上场名额 2→4**：全队星数或累计胜场达标（实际生效：星 4/10，胜 3/8；配置里的 16★/14 胜未被 `teamSlots` 读取）。
5. **保底**：战败也给金币；胜利按伤害与击杀给碎片。
6. **重置**：只清 progression，保留 settings。

明确不做：联网对战、抽卡、体力、装备、商店、赛季、排行榜、云存档、APK 壳、抖音小游戏工程、3D 管线。

## 7. 为什么取消城堡

玩家反馈：英雄全灭本来就结束战斗，城堡只是第二个胜利条件与一堆额外目标；拆城堡没有提高「杀人」的乐趣，反而分散火力与设计预算。

v3 决策：
- 删除城堡/核心/城墙/炮塔/组件崩落/炮塔每回合伤害/「拆核心」奖励线；
- 胜负只由小队存活决定；
- 原本城堡升级的金币消耗迁移为**队伍训练**三条线（存档 v2 的城墙→护甲、核心→火力、炮塔→工兵）；
- 内容量从「城堡布局」转到「地图 + 英雄 + 训练 + 名额解锁」。

## 8. 关键技术决定

- **可破坏地形**：1280×640 `Uint32Array` 像素掩码为唯一真相，`support` 为派生索引；圆坑 O(r²) 清零 + 脏矩形重绘；不引 Matter.js，避免刚体求解破坏确定性。
- **确定性模拟**：`step(state, cmd) -> Event[]` 是确定性可变 reducer（地形 3.2MB 不逐 tick 深拷贝）；固定 16ms tick，随机全部由 `(seed, turn, purpose)` 派生，全项目无 `Math.random`。
- **弹道预演**：玩家预测与 AI 评分共用同一积分器；AI 难度只改采样密度/选点噪声，不加伤害。
- **渲染**：Phaser 只画战场（地形 CanvasTexture、单位 Graphics、粒子、相机）；HUD/菜单/结算全部 DOM；`engine/**` 不 import Phaser/DOM。
- **存档**：`localStorage['bg:save:v1']` 单 JSON 信封，v3 schema，v1→v2→v3 纯函数迁移，坏档降级；战斗快照用 RLE 压缩地形，刷新可继续。

## 10. 已知偏差与缺口

1. `step` 为确定性可变 reducer，不是每 tick 深拷贝纯函数（原因：地形 3.2MB）。
2. 猝死只压单位血量，没有额外核心伤害（城堡已删除）。
3. 玩家角度 UI clamp `-6..100`，引擎接受更宽范围（`AIM` 常量）。
4. 真机 WebGL 与真机帧率未验证；headless Chromium 的 WebGL 在 swiftshader 上会 `Framebuffer Unsupported`，QA 固定 `?renderer=canvas`。
5. 渲染按 CSS 像素（DPR=1），高分屏略糊，后续可加 DPR 配置。
6. `PERF` 常量部分未接线（低帧自动降级未实现）。
7. 音效为 WebAudio 合成，无 BGM。
